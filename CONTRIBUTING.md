# Contributing

Contributions that improve reproducibility, independent implementations, portability, documentation, tests, attack tooling, or cryptanalysis are welcome.

For a cryptanalytic or conformance result, begin with `PUBLIC_REVIEW.md` and
use the repository's **Cryptanalysis or conformance finding** issue form. Exact
inputs, deterministic generators, commands, budgets, raw results, and stated
limitations make a result actionable.

Do not submit an algorithmic "strengthening" that silently changes frozen C1/M1/A1 behavior. Cryptographic changes require a documented finding, explicit candidate-version decision, new vectors and a new review cycle.
