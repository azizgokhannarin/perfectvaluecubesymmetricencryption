# Timing campaign records

These records were produced on 2026-08-16 on an Intel Core i7-10710U with the
process pinned to logical CPU 0.

- `GCC14_PRIMARY.txt`: pre-registered full primary campaign.
- `GCC14_SEED2_REPLICATION.txt`: second-seed repeats of all primary positives.
- `CLANG19_PRIMARY.txt`: full compiler-comparison campaign.
- `C1_LOCALIZATION.txt`: final key-only/frame-only matrix for two seeds and two
  compilers.

Timing measurements are host-specific research artifacts. A threshold crossing
is leakage evidence for the tested binary and host, not a practical attack or a
portable security-strength estimate.
